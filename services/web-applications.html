Services

Web application development for tools people have to use every day.

A website presents the offer. A web application is the work itself: accounts, data, and a workflow. I build portals, dashboards, and product interfaces that a team or its customers can rely on.

Included

What the engagement covers

  • The user roles and the jobs each role has to finish
  • Interface design for the main flows, including empty and error states
  • Application structure, data, and the APIs those screens need
  • Access control so people see only what they should
  • A release and a short guide for the people who will run it
A good fit

  • A client portal that still lives in email
  • An internal dashboard assembled from exports
  • A product MVP with a real workflow, not a slide
  • An existing web app that needs a senior builder for the next release
